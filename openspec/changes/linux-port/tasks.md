# Задачи порта на Linux

> **Статус (17.11.2026).** В upstream 1.1.0 появился собственный Linux-порт: `src/sys/{windows,linux}.rs`,
> свой MPRIS (`mpris-server 0.10` на zbus 5), ключница для токена, `.deb`/`.rpm`/AppImage/AUR, CI.
> Ветка `linux-port` смержена с ним: принята структура upstream, поверх неё перенесены наши
> исправления — «залипание» ввода после перетаскивания окна, `Pause`/`Stop` для медиаклавиш,
> нижний регистр кода входа и его автопродление, диагностика `YAMUSIC_INPUT_DEBUG`.
> Ниже — исходный чек-лист; пункты про femtovg и plaintext-токен заменены upstream-решением
> (Skia software, ключница).

- [ ] 4.2 MPRIS: виджет GNOME, медиа-клавиши, управление из shell — свойства проверены

- [ ] 4.3 Автозапуск, масштаб дробный (150%), femtovg-визуальный smoke-test — руками.
- [x] 4.4 deb: установка/удаление на чистом ubuntu:26.04 (контейнер), состав пакета,

- [x] 4.5 Отрисовка и ввод: окно входа нарисовано целиком (шрифты и иконки веб-версии),
      код входа — в нижнем регистре, как его принимает сервис.
- [x] 4.6 Клики под X11-бэкендом (контейнер, `xdotool`): «Скопировать код» и
      «Открыть ya.ru/device» доходят до обработчиков (в логе `клик: …`); копирование

- [ ] 4.7 Клики и обновление кадра под Wayland — проверить руками после исправления
      масштаба (убраны синтетические `ScaleFactorChanged`/`Resized`).
- [x] 4.20 Медиа-клавиша «плей/пауза»: GNOME (`gsd-media-keys`) отправляет MPRIS `Pause`, а не
      `PlayPause` (проверено `dbus-monitor`: пять вызовов `Pause` нашему плееру). Обработчик `Pause`
      (и `Stop` = пауза) не был подключён — клавиша ничего не делала, хотя кнопки в уведомлении
      работали. Добавлены `Cmd::Pause` и `connect_pause`/`connect_stop`.
- [x] 4.18 Найдена причина «кнопки не нажимаются»: после перетаскивания окна за заголовок
      композитор забирает указатель, отпускание до приложения не доходит, и Slint остаётся
      с зажатой кнопкой (нет наведения, клики уходят «захваченному» элементу). Исправлено
      отложенной доставкой отпускания (`settle_pointer_after_move`); проверено в Xvfb:
      до фикса клик после перетаскивания терялся, после — наведение и клик работают.
- [x] 4.19 Диагностика `YAMUSIC_INPUT_DEBUG=1`: счётчик кадров раз в 5 с, наведение и нажатия
      кнопок заголовка/навигации/строк/пилюль, «фон — нажато» для кликов мимо элементов.
- [x] 4.15 Слияние `origin/main` (1.0.1–1.0.2): мини-плеер, папка скачивания, медиаклавиши,
